Calliope

An unofficial GNOME desktop client for Meta’s Muse, with Quick Ask on a keyboard shortcut, background notifications and search from the Activities overview.

Install with GNOME Software

From a terminal

flatpak install --user https://zachnguyen.com/calliope/calliope.flatpakref

Updates arrive with your other Flatpak apps. The runtime comes from Flathub, which Flatpak adds if it is missing.

Source code, building from source and issues: github.com/cszach/calliope.

Calliope is an independent project. It is not made, endorsed or supported by Meta.
